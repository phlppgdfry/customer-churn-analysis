From clone to working demo.

Python 3.11+ is enough to run the application. No API key, account or paid service is required. 

git clone https://github.com/phlppgdfry/customer-churn-analysis.git
cd customer-churn-analysis
python3 -m demo.server

Then open http://127.0.0.1:8114. Your changes stay in a local SQLite database. See the README for fresh workspaces, exports and test instructions.
